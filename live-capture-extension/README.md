# 千川直播画面采集器

这是一个仅在本机使用的 Chrome / Edge 扩展。它不绕过千川登录或权限：

1. 在已登录的千川直播大屏页面中读取当前 `live_room_id`。
2. 从页面已收到的直播大屏数据里提取当前场次的签名 HTTP-FLV 地址。
3. 将地址发送到本机 `http://127.0.0.1:8765/api/live/stream`，供诊断页短时使用。
4. 诊断页优先经本机代理播放；代理失败时回退为浏览器直连 FLV。

## 安装

1. 保持本机诊断服务已启动。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录 `live-capture-extension`。
5. 打开千川直播大屏。地址应包含 `live_room_id=...`。
6. 回到诊断页，画面地址会在下一次刷新时自动接入。

若修改了服务端口，在扩展的“选项”中把地址改为对应端口。

## 数据边界

- 扩展只申请 `qianchuan.jinritemai.com` 和本机服务地址的权限。
- 签名地址仅保存在诊断服务内存中，默认 30 分钟过期，不写入 `data/qianchuan-snapshot.json`。
- 千川重新开播或 CDN 轮换签名后，保持直播大屏打开即可自动刷新。
